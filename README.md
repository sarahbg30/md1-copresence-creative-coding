# the bus

A bus ride shared with strangers. It looks shared, but everyone else on the bus is a fake rider: there is no server, and each browser tab has its own bus.

## Try the prototypes

| Prototype | Play | Fast test |
| --- | --- | --- |
| **Illustrated**: the ride as a log, with the drawn bus, road and sky | [play](https://sarahbg30.github.io/md1-copresence-creative-coding/) | [×40 speed](https://sarahbg30.github.io/md1-copresence-creative-coding/?speed=40) |
| **ASCII**: the same ride, with the bus drawn in text characters | [play](https://sarahbg30.github.io/md1-copresence-creative-coding/ascii/) | [×40 speed](https://sarahbg30.github.io/md1-copresence-creative-coding/ascii/?speed=40) |
| **p5.js**: the bus from the side, riders in the windows, the story on the frosted glass | [play](https://sarahbg30.github.io/md1-copresence-creative-coding/bus-p5/) | [×40 speed](https://sarahbg30.github.io/md1-copresence-creative-coding/bus-p5/?speed=40) |

In the p5.js version: arrow keys (or the ‹ › buttons on a phone, held sideways) to walk along the bus, and the button under your window to do your one action.

## Where the code is

- Illustrated: `docs/` (`index.html`, `client.js`, `game.js`)
- ASCII: `docs/ascii/`
- p5.js: `docs/bus-p5/sketch.js`, using the rules and drawings in `docs/bus/`
